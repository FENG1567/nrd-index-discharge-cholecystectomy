# Changelog

## 1.0.0 - public reproducibility package

- Added a public aggregate-only pathway for the six manuscript figures.
- Added portable licensed-rerun scripts with explicit path arguments and an eight-worker default.
- Added sanitized codebook and 2018-2022 Core/Severity/Hospital layout specifications.
- Added aggregate source data, data dictionary, reference figure files, tables, legends, tests, CI, and checksums.
- Excluded NRD archives, patient-level records, linkage keys, hospital identifiers, fitted nuisance predictions, credentials, logs, and internal working materials.
- Preserved HCUP small-cell suppression (`<11`) in all public tabulations.
